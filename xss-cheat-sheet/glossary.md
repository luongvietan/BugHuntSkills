# Glossary — XSS Cheat Sheet (Brute Logic)

**2nd-order XSS** — stored input decoded/applied later (DB→DOM), bypassing first-pass filters (Sec 3)
**Agnostic event handler** — `<x on*>` vector working with any alphabetic tag name; needs user interaction (Sec 3)
**Alert obfuscation** — indirect alert calls (`top["al"+"ert"](1)`, `[1].find(alert)`) to beat regex filters (Sec 3)
**AngularJS sandbox escape** — `{{constructor.constructor('alert(1)')()}}` for ng ≥1.6 (Sec 2)
**ASCII encoding table** — char→URL/entity/octal/hex/unicode map used to build bypasses (Sec 5)
**Blind XSS** — payload firing in a context the tester can't see (admin panel); needs callback collector (Sec 4)
**Block tag** — `<title><style><script><textarea><noscript><pre><xmp><iframe>`; requires `</tag>` breakout (Sec 1)
**CSP bypass** — executing via whitelisted domains (e.g., Google JSONP endpoints) (Sec 3)
**CRLF injection** — `%0D%0A` in reflected response headers to forge Location/Content-Type/body (Sec 2)
**Crosspwn** — PHP tool firing postMessage/onresize/onhashchange cross-origin; origin-bypass helper (Sec 5)
**CSTI** — client-side template injection; probe `{{32*32}}`→1024 (Sec 2)
**data: URI XSS** — `data:text/html,<svg onload=alert(1)>` in href/src/url-fetch sinks (Sec 1,2)
**DOM insert injection** — payload inserted as live markup by page JS, not reflected in source (Sec 2)
**Double-encoded XSS** — `%253C` surviving two decode passes (Sec 3)
**Event origin bypass** — allowed origin as subdomain of attacker domain (`facebook.com.localhost`) (Sec 3)
**File upload XSS** — filename reflection, EXIF metadata, or SVG-content stored XSS (Sec 2)
**GIF disguise** — `GIF89a=//<script>…` polyglot bypassing MIME checks → CSP bypass via upload (Sec 3)
**httpOnly** — cookie flag making cookies unreadable to `document.cookie` — exfil fails (Sec 4)
**Inline injection** — attribute-value injection without `>`; event-handler based (Sec 1)
**Logical block injection** — breaking out of string literal *and* enclosing function/conditional (`'}alert(1);{'`) (Sec 1)
**Multi-case injection** — one-shot `'"</Script><Html /Onmouseover=(alert)(1) //` covering several contexts (Sec 5)
**Multi-reflection** — same input echoed 2–3×; fragment payloads chain across reflections (Sec 2)
**PHP_SELF injection** — URL path reflected in form action; inject after `.php/` before `?` (Sec 2)
**postMessage XSS** — exploiting `message` listeners lacking origin validation; needs frameable target (Sec 2)
**Remote script call** — short bootstrap loading external JS/HTML via XHR/fetch/script-append (Sec 4)
**Shortest XSS** — `<base href=//host>` + native relative script → attacker-served payload (Sec 5)
**Strip-tags bypass** — `o<x>nmouseover` fragments surviving `<…>` stripping (Sec 3)
**Unclosed tag** — `<svg onload=alert(1)//` without `>`; needs native `>` after reflection (Sec 3)
**Virtual defacement** — `documentElement.innerHTML=` overwrite via event handler (Sec 4)
**XFO / X-Frame-Options** — header controlling frameability; gates iframe-based vectors (Sec 2,4)
**XML XSS** — namespaced `<x:script xmlns:x=…>` for `text/xml`/`application/xml` pages (Sec 2)
