# Glossary — zseano's methodology

**anew** — TomNomNom tool diffing new vs old domain lists (toolkit)
**amass** — OWASP subdomain enumerator (passive+active+alterations) (toolkit)
**aquatone** — visual triage of domains/endpoints via screenshots (toolkit)
**ATO** — account takeover
**Blind XSS** — payload fired in unseen context (admin panels); needs callback collector (ch03)
**BOLA / IDOR** — object-ID manipulation for unauthorized access (ch04)
**Business logic bug** — misuse of intended flows; no payload needed (ch04)
**canEdit flag** — client-side permission flag; flip/test server-side (ch07)
**CORS misconfig** — substring/wildcard origin checks readable cross-domain (ch04)
**Credential/reset token leak** — via Host-header trust or open-redirect chains (ch05)
**CSRF referer check** — bypass via absent referer or domain-substring tricks (ch03)
**dnsgen** — permutation-based subdomain discovery (toolkit)
**Dorking** — search-engine recon for indexed endpoints/files/secrets (ch06)
**Filter hunting** — first-pass goal: find protections to bypass, not just bugs (ch01, ch03)
**ffuf** — fast web fuzzer for files/dirs/params (toolkit)
**Grep-Match** — Burp Intruder feature grepping responses across many hosts (ch06)
**Host-header injection** — reset links built from attacker Host → token leak (ch05)
**HPP** — HTTP parameter pollution, e.g. extra `id=` (ch04)
**httprobe** — probes live http/https services incl. custom ports (toolkit)
**Mass assignment-style param injection** — adding `{"id":"1"}` into JSON bodies (ch04)
**Open redirect** — unvalidated redirect param; chained with OAuth = token theft (ch04)
**ParamScanner/InputScanner** — scrapes input names/ids + JS vars → param candidates (ch02, ch06)
**Patch bypass** — re-exploiting after a fix; fixes are often local/bypassable (ch07)
**robots.txt** — disallowed paths = hidden content map; per-subdomain triage signal (ch06)
**Sandbox/test CC** — always-true payment numbers; bypasses payment-gated verification (ch05, ch07)
**Second-order / stored XSS** — payload persisting to a later/different context (ch03)
**Shadow feature** — code shipped before feature enabled; enable via flag flip (ch06, ch07)
**SSRF redirect bypass** — filter checks input host, not redirect destination (ch04, ch07)
**`$_GET` vs `$_POST`** — same param may be filtered in one method only (ch06)
**VDP** — vulnerability disclosure program; practice surface with limits (ch01)
**WaybackMachine recon** — historical robots/homepage/files → forgotten vulnerable code (ch02, ch06)
**Wide-scope program** — many in-scope domains; methodology's preferred target (ch01)
**X-FRAME-OPTIONS** — missing header enabling iframe-based CSRF chains (ch07)
