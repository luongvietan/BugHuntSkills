# Glossary — OWASP API Security Top 10 (2019)

**API key** — client app/project credential; not user authentication (API2)
**BFLA** — Broken Function Level Authorization; wrong-role access to functions/endpoints (API5)
**BOLA** — Broken Object Level Authorization; ID-swap unauthorized object access, a.k.a. IDOR (API1)
**Credential stuffing** — replaying breached user/pass lists against login (API2)
**CORS** — Cross-Origin Resource Sharing; misconfigured origins allow cross-site reads (API7)
**Deny by default** — authz posture granting nothing without explicit per-role allow (API5)
**Detectability** — OWASP score: how easy the flaw is to find (1 hard–3 easy)
**Excessive data exposure** — API returns fields the UI filters client-side (API3)
**Exploitability** — OWASP score: ease of attack (1 difficult–3 easy)
**GUID** — random unpredictable object ID; reduces enumeration, not a control by itself (API1)
**Horizontal privilege escalation** — accessing another same-role user's objects (API1)
**Injection** — untrusted data reaching SQL/NoSQL/LDAP/OS/XML/ORM interpreters (API8)
**JWT `alg:none`** — unsigned-token attack when verification is missing (API2)
**Log injection** — forging/corrupting log entries via unsanitized input (API10)
**Mass assignment** — auto-binding client input to object props without whitelisting (API6)
**NoSQL operator injection** — `param[$ne]=x` / `{"$regex":".*"}` query manipulation (API8)
**OTP/verification code** — short numeric token needing strict rate limiting (API2)
**Prevalence** — OWASP score: how common the flaw is (1–3)
**Rate limiting** — per-client request caps; absence enables brute force + DoS (API4)
**Risk rating** — OWASP method: Threat Agents × Exploitability × Prevalence × Detectability → Technical + Business impact (RISK)
**Security headers** — CSP/HSTS/XFO/etc.; missing = misconfiguration signal (API7)
**Shadow/legacy API** — unversioned, beta, staging, or retired-but-running hosts (API9)
**SIEM** — Security Information & Event Management; log aggregation + alerting (API10)
**Stack trace leak** — verbose errors exposing internals (API7)
**Vertical privilege escalation** — reaching higher-privilege functions/objects (API5)
**Whitelist binding** — only named client-writable props may be assigned (API6)
